# Code of Conduct

## Principles

This project follows the spirit of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), distilled to:

1. **Assume good intent.** Disagreements about engineering trade-offs are normal — personal attacks are not.
2. **Frame critique on the work, not the person.** Especially relevant for a tool that analyzes other people's code.
3. **The tool's anti-misuse principles apply to this community too.** Conversations that frame individual developers as "AI users" or "non-AI users" based on heuristic signals are not acceptable here.
4. **Privacy first.** Do not paste private code, secrets, or identifying information into issues or PRs.

## Enforcement

Reports of unacceptable behavior can be sent privately via GitHub direct message to the maintainer ([@karel008-sudo](https://github.com/karel008-sudo)) or via [LinkedIn](https://linkedin.com/in/karel-prochazka).

The maintainer will respond within 5 working days. Possible responses range from a private clarification to a permanent ban from the project, depending on severity.

## Scope

This Code of Conduct applies to all project spaces — issues, pull requests, discussions, and any direct communication relating to the project.
